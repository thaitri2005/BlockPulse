# Documentation

Start with the [project README](../README.md) for what BlockPulse is and what it showed.

| Folder or file | What it is | Changes when |
| --- | --- | --- |
| [ARCHITECTURE.md](ARCHITECTURE.md) | How the system is built: data flow, runtimes, commands, modules, technology, limits | The system changes |
| [PROJECT_PLAN.md](PROJECT_PLAN.md) | Purpose, current status, candidate next work, decisions, risks | Status or direction changes |
| [guides/](guides/) | One how-to per part of the system, with its measured results | That part changes |
| [learning/](learning/README.md) | Exercises that walk through the code, one concept at a time | An exercise is written |
| [experiments/](experiments/README.md) | Dated reports and raw run output: the evidence behind every figure | Something is measured. Never edited afterwards except to correct an error |
| [archive/](archive/) | The original design and the milestone history. Kept for reference, not maintained | Never |

Rules for keeping it tidy: a fact lives in one place and other pages link to it; guides explain how and report results, experiments record what happened on a date; nothing in the README, the architecture or the plan is a log.
